# AI Developer - Легковесное веб-приложение

Веб-приложение, которое выступает в роли AI-разработчика, используя Gemini API для генерации кода, локальный Git для версионирования и Docker для изолированного деплоя проектов.

## Требования к ресурсам
- Минимум: 2GB RAM, 1vCPU
- Оптимизировано для работы на слабых серверах

## Установка

### 1. Установка зависимостей
```bash
apt update
apt install -y python3-pip python3-venv docker.io nginx git curl
pip3 install flask flask-login flask-cors requests python-dotenv
```

### 2. Настройка приложения
```bash
# Скопируйте .env.example в .env и настройте
cp .env.example .env
# Отредактируйте .env и укажите ваш GEMINI_API_KEY
```

### 3. Запуск
```bash
python3 app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Функционал

### Авторизация
- Гибкая система авторизации (пользователи/администраторы)
- Поддержка нескольких пользователей
- Безопасное хранение паролей

### Чат с AI
- Генерация кода через Gemini API
- Контекстная память диалога
- Поддержка различных языков программирования

### Управление проектами
- Создание новых проектов
- Автоматическое версионирование через Git
- Docker-изоляция для каждого проекта
- Экспорт/импорт проектов
- Удаление проектов с очисткой ресурсов

### Управление контейнерами
- Автоматическая проверка свободных портов
- Очистка неиспользуемых ресурсов Docker
- Мониторинг состояния контейнеров

### Веб-интерфейс
- Минималистичный дизайн
- Адаптивный интерфейс
- Настройки приложения
- Логи и мониторинг

## Безопасность

- IP-based доступ без обязательного домена и SSL
- Защита API ключей
- Изоляция проектов через Docker
- Регулярная очистка временных файлов

## Структура проекта

```
/ai-developer/
├── app.py                 # Основное приложение
├── config.py              # Конфигурация
├── models.py              # Модели данных
├── auth.py                # Система авторизации
├── gemini_client.py       # Клиент для Gemini API
├── docker_manager.py      # Управление Docker
├── project_manager.py     # Управление проектами
├── templates/             # HTML шаблоны
├── static/                # Статические файлы
└── projects/              # Директория проектов
```

## API Endpoints

- `POST /api/login` - Вход в систему
- `POST /api/logout` - Выход из системы
- `GET /api/projects` - Список проектов
- `POST /api/projects` - Создание проекта
- `DELETE /api/projects/<id>` - Удаление проекта
- `POST /api/chat` - Отправка сообщения AI
- `GET /api/containers` - Список контейнеров
- `POST /api/containers/cleanup` - Очистка ресурсов
